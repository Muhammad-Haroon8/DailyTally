# DailyTally

DailyTally is a comprehensive daily accounting, ledger, and customer tally management system consisting of:
- **Backend**: Node.js, Express, MongoDB REST API.
- **Mobile App**: React Native (Expo) app for managing customers, daily accounts, vouchers, items, and payments.

## Structure
- `/backend` - Express API with MongoDB Mongoose models and controllers.
- `/mobile` - React Native Expo mobile application.
